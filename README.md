# AnythingToQR

A fast, lightweight, and 100% client-side QR code generator and scanner. Runs entirely in your browser with zero data sent to external servers.

- **Live Application:** [https://t3crypt.github.io/AnythingToQR/](https://t3crypt.github.io/AnythingToQR/)
- **Repository:** [https://github.com/T3Crypt/AnythingToQR](https://github.com/T3Crypt/AnythingToQR)

---

## Features

- **Universal Formats:** URL, Plain Text, WiFi credentials, vCard contacts, Email, SMS & WhatsApp, Direct Phone Dial, and Cryptocurrency wallet addresses.
- **QR Scanner:** Integrated decoder supporting live camera scanning, file upload, clipboard paste (`Ctrl+V`), and drag-and-drop.
- **Customization:** Multiple dot styles (Square, Dots, Rounded, Classy), corner frame options, color controls, and center emblem/logo support.
- **High-Resolution Export:** Download in raster PNG (up to 1024px) or vector SVG format.
- **Direct Clipboard Copy:** Copy generated QR images straight to your clipboard with one click.
- **Privacy First:** 100% in-memory processing. No telemetry or external server tracking.

---

## Local Usage

Open `index.html` directly in any modern browser, or serve locally:

```bash
python -m http.server 8000
```

Navigate to `http://localhost:8000`.
